# VV妮可科研绘图·数据驱动科研绘图

噜噜 pastel 水豚主题：奶油底 + 暖橙渐变 + 圆角卡片 + SVG 小水豚吉祥物。

单文件静态页：`figstudio.html`，**下载后用 Chrome/Edge 直接打开**（勿在 Muse 聊天窗口的文件预览里使用——预览 iframe 会限制对外网络，API 拉取/调用失败）。数据只在浏览器本地解析，不上传服务器。

## 流程（4 步）

1. **投喂数据**：拖入 `.zip`（内含 CSV）、单个 CSV，或复制文件后 Ctrl+V 直接粘贴；也可点"载入示例数据"试玩。另有**论文原文 / 研究逻辑**输入框（可折叠，localStorage 持久化）。
2. **图类型推断**：规则引擎按列类型（数值 / 分类 / 时间）推断数据能支撑的图类型，给出推荐列映射；另有**数据关系发现**（Pearson 强相关 |r|≥0.6、组间差异 η²≥0.14、疑似 ID 列、多文件关联键、时间趋势，每条可一键绘图）和**论文逻辑 → 数据映射**（把研究逻辑逐条映射到数据列并推荐贴合的图）。
3. **样板图库**：10 种图 × 5 种期刊风（学术蓝/Nature/Science/Cell/柔和灰蓝）= 50 个样板，程序化生成（含配色预览条、风格筛选）；绿色徽标 = 你的数据可支撑；点"用此样板绘制"自动套用该样板的配色/字体/网格。支持导入第三方索引 JSON。**我的样板**：从期刊图截图投喂→AI 解析配色/字体/网格存成样板（视觉模型），或手动配色创建（颜色选择器，离线）；样板存本浏览器，可删除、可导出样板包分享、可导入样板包。另有**论文配图灵感**卡：按需加载顶会画廊 3516 张真实配图索引（会议/类型/标题筛选，图片懒加载），仅作视觉灵感参考、不直接绘图。
4. **绘制导出**：选文件 + 图类型 + 列映射，ECharts 实时渲染，可调配色 / 字体 / 网格 / 标题，导出 PNG（3x）/ SVG。

## 技术

- ECharts 5（CDN）+ JSZip（CDN），需联网；离线时页面会提示。
- 相关热图走 Pearson 相关（JS 自算）；箱线图走 min/Q1/中位/Q3/max；森林图走 custom series。
- 配色默认"学术蓝"。示例数据为通用随机数据，不含任何真实论文信息。

## 已知限制

- 纯前端无法自动全网抓取期刊样板图（反爬 / 跨域 / 版权）；样板库为程序化生成的 50 个 + 支持导入外部索引；3516 张顶会画廊仅作灵感浏览。
- CSV 解析上限 10 万行/文件，超出截断并提示。
- 未做浏览器实测：JS 语法检查 + 数据逻辑单测通过，无头 Chromium 在本环境无法启动。

## API 集成（AI 增强，可选）

步骤 1 **API 设置**卡：服务商预设（硅基流动/DeepSeek/火山方舟/智谱/Kimi/通义千问/自定义中转站）+ Base URL + API Key + 备用线路 + 对话模型 + 视觉模型，OpenAI 兼容格式（`/chat/completions`），Key 只存本浏览器 localStorage。支持**主/备用双线路自动 failover**；**模型选择**借鉴 FigureForge：实时拉取成功按"你的账号已开通"分组，失败则静默降级用内置推荐清单；Key 粘贴时自动清洗空白字符；**网络诊断**可定位网络层/CORS/页面环境问题。

三个 AI 功能：

1. **AI 复核推荐**（步骤 2）：把各文件的列名/列类型/行数 + 研究逻辑节选发给对话模型，返回补充的图类型建议（JSON），渲染为"AI 建议"卡片。
2. **生成英文图注**（步骤 4）：AI 版按当前图类型、列映射、汇总统计量生成学术英文 caption；另有**本地离线版**（模板生成，按图类型/变量/n/统计量拼 caption，散点图自动带 Pearson r），无网络照样用。
3. **AI 风格迁移**（步骤 4）：按所选样板生成 ECharts 样式 JSON（配色/字体/网格），一键应用；可勾选"让模型看样板图"走视觉模型（缩略图转 PNG dataURL 发送）。离线替代：样式区配色下拉框有 Science / Cell 等期刊配色，即时生效。

隐私边界：AI 只接收列名、列类型、汇总统计量，原始数据行不出浏览器；绘制仍走本地确定性渲染，不虚构数据点。
